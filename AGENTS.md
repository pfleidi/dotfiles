# Repository instructions

## Documentation

- Document current behavior and the context needed to use or maintain it.
- Do not record plans, deferred work, or decisions about doing work now versus later.
- Keep the README focused on the repository rather than cataloging personal, work, or machine-specific setups.
- Keep credentials, machine-local repository roots, private repository inventories, and other private configuration out of version control.

## Starship

- Apply Starship configuration changes to `config/starship.toml` and every file in `config/starship/*.toml`, unless the change only affects a color palette. Palette-only changes may be limited to the relevant configuration.
